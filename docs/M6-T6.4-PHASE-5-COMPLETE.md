### 3. 关键不变式实现

**核心不变式:**
> 一旦接受逻辑操作并分配 operationId，
> 该逻辑操作必须在物理副作用能力调用被允许之前
> 成为持久化可达的。

**实现验证:**
```java
// 1. 分配 operationId
String operationId = "OP-" + UUID.randomUUID();

// 2. 构建 PendingToolCall
PendingToolCall pending = new PendingToolCall(operationId, ...);

// 3. 构建 RUNNABLE checkpoint
SuspensionCheckpoint checkpoint = new SuspensionCheckpoint(..., 
    ContinuationDisposition.RUNNABLE, 
    pendingBatch, ...);

// 4. DURABLE COMMIT (必须成功)
checkpointStore.create(checkpoint);  // 失败 = 抛异常，无副作用

// 5. Phase 6 TODO: 物理工具调用
```
