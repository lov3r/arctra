# Arctra — 开始这里

正式项目名：

```text
Arctra
```

Maven GroupId / Java Base Package：

```text
cn.bitcss.arctra
```

第一步不要写 Runtime。

在项目根目录启动 Claude Code，然后让它按照 `CLAUDE.md` 和 `docs/DOCUMENT-MAP.md` 建立上下文，只规划 `BOOT-001`。

BOOT-001 的第一批输出必须确认：

- Maven Parent
- GroupId `cn.bitcss.arctra`
- `arctra-*` Module Naming
- Java / Spring Boot / Spring AI Versions
- Module Dependency Graph
- Architecture Tests
- CI Baseline

确认计划后才允许编码。
